Глава с этого кадра

Главы и описание

Главы ставятся на кадры: кнопка «Глава» в редакторе под шкалой или «Предложить» здесь. Время берётся из разметки.

Резервная копия

Копия забирает картинки, озвучку, музыку, звуки, текст, промты и всю разметку в одну папку. Выберите флешку, облачную папку или другой диск: после переустановки Windows проект можно будет вернуть кнопкой «Восстановить».

Проверка перед сборкой

Разбор ритма

Каждый столбик это один кадр, его высота это длина. Наведите курсор, чтобы увидеть кадр. Нажмите, чтобы перейти к нему в редакторе.

Shorts 9:16

Вертикальное видео 1080x1920 из этого же проекта: картинка по центру на размытом фоне, субтитры по центру.

Сократить паузы

Программа найдёт в озвучке долгие паузы и вырежет из них лишнее. Тайминги кадров и слов пересчитаются сами. Исходный файл останется на месте, новый звук сохранится рядом с ним.

Очередь рендера

Отметьте проекты: они соберутся по очереди в одну папку.

Озвучка (ElevenLabs)

Нужен ваш ключ API ElevenLabs. Он хранится только на этом компьютере.

Генерация картинок в Gemini

Вставьте промты: каждая сцена отделяется пустой строкой. Сначала нажмите «Открыть Gemini» и один раз войдите в аккаунт Google в открывшемся окне Chrome.
Сцен: 0 Пауза между сценами
Готово: 0
Сделайте эти картинки в Gemini вручную и нажмите «Выбрать файл» у нужной сцены: картинка встанет ровно на своё место. Можно и просто положить файл с именем image_НОМЕР.png в папку проекта.
